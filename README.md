# CodeAlpha C Programming Internship

This repository contains the C programming projects completed as part of the CodeAlpha C Programming Internship.

## Projects

### Task 1 - Calculator
A menu-driven calculator program using functions and switch-case.

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

### Task 2 - Matrix Operations
A matrix operations program using functions and 2D arrays.

Features:
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose
- Input validation

### Task 3 - Student Management System
A menu-driven student management system using structures and file handling.

Features:
- Add Student
- Delete Student
- Update Student
- Search Student
- Display All Students
- File Storage

### Task 4 - Banking System
A menu-driven banking system using structures, functions and file handling.

Features:
- Create Account
- Deposit
- Withdraw
- Balance Enquiry
- Display Account Details
- Search Account
- Transaction History
- Multiple Accounts
- File Storage

## Technologies Used

- File Handling
- Menu-driven Programming
